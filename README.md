# Student Grade Calculator

A simple Python application that calculates the average grade of a student
and determines whether the student passes.

## Installation

```bash
pip install -r requirements.txt
```

## Run Tests

```bash
pytest -v
```

## Run Linting

```bash
flake8 .
```
